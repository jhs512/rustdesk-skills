# jhs512-rust-desk:listen

사용자가 `jhs512-rust-desk:listen`을 실행하면 휴대폰에서 말하는 음성을 입력받도록 아래 설정을 수행한다. 이 문구는 전역 설치에서도 인식할 자연어 호출어다. 콜론을 사용하는 플러그인 명령 이름은 플러그인 호스트의 등록 방식에 따른다.

> RustDesk 연결 창에서 통화 ‘수락’을 누르고 3초간 기다린 다음, ‘Audio input(오디오 입력)’ 메뉴에서 ‘시스템 소리’를 선택한다.

## 필수 의존성

- macOS에서 실행 중인 **RustDesk** 연결 창(예: 우측 상단에 떠 있는 `<ID> - RustDesk` / 세션 제어 패널)과 휴대폰에서 걸려온 수신 통화 또는 진행 중인 통화.
- **macos-mcp (맥 MCP)** 연결. 필수 도구는 `Snapshot`, `Click`, `Wait`(필요 시 `App`)다. 호스트가 붙이는 도구 접두어는 달라도 된다.
- macos-mcp 실행 프로세스에 필요한 macOS 접근성 및 화면 기록 권한.

스킬 자체는 MCP 서버를 설치하거나 실행하지 않는다. 연결된 도구를 검색하여 확인하고, 연결 또는 권한이 없으면 원인을 알리고 중단한다.

## 중요 주의사항 (속도 및 정확도)

1. **접근성 목록(`Interactive Elements`)에 의존하지 말고 스크린샷(`use_vision=true`) 좌표로 즉시 클릭한다.**
   - RustDesk 연결 창은 Flutter 기반 보조 창이므로 `Snapshot`의 텍스트 접근성 목록(`Interactive Elements`)에 내부 버튼(`수락`, `Audio input`, `시스템 소리`)이 나타나지 않는다.
   - 스크린샷에 그려진 다른 앱(Antigravity 등)의 보라색 번호 박스 좌표는 오프셋이 어긋나 있을 수 있으므로 기준 삼지 않는다.
2. **화면 우측 상단에 RustDesk 연결 창이 이미 보이면 절대 `App(mode="switch")`를 호출하지 않는다.**
   - `App(mode="switch", name="RustDesk")`나 `Paseo` 전환을 호출하면 우측 상단의 플로팅 연결 창(`<ID> - RustDesk`)이 독(Dock)으로 최소화되거나 가려진다.
   - 만약 연결 창이 화면에 안 보이고 Dock에 `<ID> - RustDesk` 아이템으로 최소화되어 있을 때만 Dock 아이콘을 클릭해 복원한다.
3. **버튼 위치와 역할을 정확히 구분한다.**
   - 상단 `권한` 영역의 스피커 아이콘(세 번째 파란 아이콘)은 `오디오 허용: ON/OFF` 권한 토글이지 통화 오디오 입력 메뉴가 아니다.
   - 통화 관련 버튼은 창 하단 `연결 해제` 버튼 바로 위 행(좌측 파란 버튼, 우측 빨간 버튼)에 위치한다.
   - 통화 수락 전에는 좌측 파란 버튼이 **`수락`**(우측은 `거부`)이고, 수락 후 연결되면 같은 자리의 좌측 파란 버튼이 **`Audio input`**(또는 `오디오 입력`, 우측은 `음성 통화 종료`)으로 바뀐다.
   - 기본 우측 상단 배치(`1470x956` 논리 좌표계, 창 범위 `x: 1170..1470, y: 33..523`)에서 이 좌측 파란 버튼(`수락` / `Audio input`)의 영역은 `x: 1185..1315, y: 445..470`이며 **정중앙 좌표는 `(1248, 458)`** 부근이다. (`y=471..479`는 `연결 해제` 버튼과의 사이 빈 공간이므로 `y=476`처럼 버튼 아래쪽을 클릭하지 않도록 주의한다.)

## 실행

1. `Snapshot(use_vision=true)`으로 현재 화면 이미지를 확인한다.
2. RustDesk 연결 창 하단 좌측 파란 버튼이 `수락`이면 버튼 정중앙(기본 배치 기준 `(1248, 458)` 부근, 실제 이미지 위치 확인)을 `Click`하고 `Wait(duration=3)`으로 3초간 기다린다. 이미 통화 중이어서 `Audio input`(`오디오 입력`) 버튼이 보이면 수락 단계는 건너뛴다. 수신 통화도 진행 중인 통화도 없으면(`연결 해제`만 있는 경우) 그 상태를 알리고 종료한다.
3. 수락을 눌렀다면 새 `Snapshot(use_vision=true)`에서 좌측 파란 버튼이 `Audio input`(`오디오 입력`)으로 바뀌었는지 확인한다.
4. `Audio input`(`오디오 입력`) 버튼 정중앙(기본 배치 기준 `(1248, 458)` 부근)을 `Click`하여 오디오 입력 선택 팝오버 메뉴를 연다.
5. `Snapshot(use_vision=true)`으로 열린 팝오버에서 `시스템 소리` 라디오 옵션의 좌표를 확인하고 `Click`한다. 이미 선택되어 있으면 유지한다. `MacBook Air 마이크` 등 마이크 옵션과 구분한다.
6. 새 `Snapshot(use_vision=true)`에서 `시스템 소리` 선택 상태를 확인한 뒤 완료를 보고한다.

통화 종료(`음성 통화 종료`), `연결 해제`, 다른 오디오 설정 변경은 작업에 포함하지 않는다.

## 완료 보고

“휴대폰 음성을 입력받도록 오디오 입력을 ‘시스템 소리’로 설정했습니다.”라고 짧게 알린다. 이미 설정되어 있었다면 그 사실을 알린다. 관찰하지 않은 실제 음성 수신이나 전사 성공까지 보장하지 않는다.

선택 영역은 ‘오디오 입력 선택 메뉴’ 또는 ‘팝오버’라고 부른다. ‘툴팁’으로 안내하지 않는다.
