# jhs512-rust-desk:listen

사용자가 `jhs512-rust-desk:listen`을 실행하면 휴대폰에서 말하는 음성을 입력받도록 아래 동작을 **중간 스냅샷 없이 빠르게 연속 실행**한다.

> 마우스를 `수락` 버튼으로 이동 → 1초 대기 → `수락` 클릭 → 1초 대기 → `Audio input`으로 변한 같은 버튼 다시 클릭 → 1초 대기 → `시스템 소리` 클릭

## 필수 의존성

- macOS에서 실행 중인 **RustDesk** 연결 창(우측 상단 기본 위치 `x: 1170..1470, y: 33..523`)과 휴대폰에서 걸려온 수신 통화.
- **macos-mcp (맥 MCP)** 연결. 필수 도구는 `Move`, `Click`, `Wait`(필요 시 `Snapshot`)다.

스킬 자체는 MCP 서버를 설치하거나 실행하지 않는다.

## 실행 (고속 실행 절차)

중간마다 `Snapshot`을 찍어 이미지를 읽으면 수십 초가 지연되므로, `skills/listen/SKILL.md`를 읽는 것도 생략 가능하면 생략하고 **아래 7단계를 한 턴에 순서대로 바로 호출**한다:

1. `Move(loc=[1248, 465])` — RustDesk 연결 창의 통화 `수락` 버튼 위치로 커서 이동 (Flutter 창 호버 인식용)
2. `Wait(duration=1)` — 1초 대기
3. `Click(loc=[1248, 465])` — 통화 `수락` 버튼 클릭
4. `Wait(duration=1)` — 1초 대기 (수락 후 같은 위치의 버튼이 `Audio input`으로 변경됨)
5. `Click(loc=[1248, 465])` — `Audio input`으로 변한 버튼 다시 클릭 (오디오 입력 팝오버 열기)
6. `Wait(duration=1)` — 1초 대기
7. `Click(loc=[1310, 468])` — 팝오버의 `시스템 소리` 라디오 옵션 클릭

### 주의사항

- `App(mode="switch")`를 호출하지 않는다(호출 시 우측 상단 RustDesk 플로팅 연결 창이 최소화됨).
- `Snapshot`의 텍스트 접근성 목록(`Interactive Elements`)에는 RustDesk 내부 버튼이 나오지 않으므로 접근성 목록을 탐색하지 않는다.
- 기본 좌표로 동작하지 않은 경우에만 `Snapshot(use_vision=true)`으로 창 위치를 확인해 좌표를 보정한다.
- 통화 종료(`음성 통화 종료`), `연결 해제`는 절대 누르지 않는다.
