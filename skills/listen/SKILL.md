# jhs512-rust-desk:listen

사용자가 `jhs512-rust-desk:listen`을 실행하면 휴대폰에서 말하는 음성을 입력받도록 아래 설정을 수행한다. 이 문구는 전역 설치에서도 인식할 자연어 호출어다. 콜론을 사용하는 플러그인 명령 이름은 플러그인 호스트의 등록 방식에 따른다.

> 파세오에서 ‘통화 수락’을 누르고 3초간 기다린 다음, ‘오디오 입력’ 메뉴에서 ‘시스템 소리’를 선택한다.

## 필수 의존성

- macOS에서 실행 중인 Paseo(파세오)와 휴대폰에서 걸려온 수신 통화 또는 진행 중인 통화.
- **macos-mcp (맥 MCP)** 연결. 필수 도구는 `Snapshot`, `App`, `Click`, `Wait`다. 호스트가 붙이는 도구 접두어는 달라도 된다.
- macos-mcp 실행 프로세스에 필요한 macOS 접근성 및 화면 기록 권한.

스킬 자체는 MCP 서버를 설치하거나 실행하지 않는다. 연결된 도구를 검색하여 확인하고, 연결 또는 권한이 없으면 원인을 알리고 중단한다. 다른 UI 도구로 임의 대체하지 않는다.

## 실행

1. `Snapshot(use_vision=true)`으로 현재 화면을 확인한다. Paseo 창이 가려져 있으면 `App(mode="switch", name="Paseo")`으로 전환한 뒤 다시 확인한다.
2. 수신 통화의 ‘통화 수락’ 버튼을 클릭하고 `Wait(duration=3)`으로 클릭 이후 3초간 기다린다. 이미 통화 중이면 수락 단계는 건너뛴다. 수신 통화도 진행 중인 통화도 없으면 그 상태를 알리고 종료한다. 직접 발신하지 않는다.
3. 새 스냅샷에서 연결 상태를 확인한다. 연결 중이면 최대 15초 동안 1~3초 간격으로 재확인한다. 연결되지 않으면 관찰한 상태를 알리고 종료한다.
4. 통화의 ‘오디오 입력’ 버튼을 눌러 선택 메뉴를 연다. `Audio Input` 등 실제 화면의 라벨을 따른다. 메뉴가 이미 열려 있으면 다시 누르지 않는다. 현재 UI로 대상을 식별하고 저장된 좌표를 재사용하지 않는다. 스크린샷 표시 크기와 클릭 좌표 단위가 다르면 좌표계를 확인한다.
5. ‘시스템 소리’ 라디오 옵션을 선택한다. 이미 선택되어 있으면 유지한다. ‘MacBook Air 마이크’ 등 마이크 옵션과 구분한다. 대상 버튼이나 옵션이 없으면 현재 상태를 설명하고 종료한다.
6. 새 스냅샷에서 ‘시스템 소리’ 선택 표시를 확인한다. 메뉴가 닫혀 확인이 안 되면 다시 열어 확인한다. 선택 상태를 관찰했을 때만 설정 완료로 보고한다.

통화 종료, 다른 상대 선택, 다른 오디오 설정 변경은 작업에 포함하지 않는다. 실패한 클릭을 확인 없이 반복하지 않는다.

## 완료 보고

“휴대폰 음성을 입력받도록 오디오 입력을 ‘시스템 소리’로 설정했습니다.”라고 짧게 알린다. 이미 설정되어 있었다면 그 사실을 알린다. 관찰하지 않은 실제 음성 수신이나 전사 성공까지 보장하지 않는다.

선택 영역은 ‘오디오 입력 선택 메뉴’ 또는 ‘팝오버’라고 부른다. ‘툴팁’으로 안내하지 않는다.
