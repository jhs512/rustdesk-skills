# jhs512-rust-desk:listen

사용자가 `jhs512-rust-desk:listen`을 실행하면 휴대폰에서 말하는 음성을 입력받도록 아래 동작을 **중간 스냅샷 없이 한 턴에 연속 실행**한다.

> RustDesk 창 포커스 클릭 → `수락` 버튼으로 이동 → 1초 대기 → `수락` 클릭 → 2초 대기 → `Audio input`으로 변한 버튼 다시 클릭 → 1초 대기 → `시스템 소리`로 이동 → 1초 대기 → `시스템 소리` 클릭

## 필수 의존성

- macOS에서 실행 중인 **RustDesk** 연결 창(우측 상단 기본 위치 `x: 1170..1470, y: 33..523`)과 휴대폰에서 걸려온 수신 통화.
- **macos-mcp (맥 MCP)** 연결. 필수 도구는 `Move`, `Click`, `Wait`(필요 시 `Snapshot`)다.

스킬 자체는 MCP 서버를 설치하거나 실행하지 않는다.

## 실행 (고속 실행 절차)

중간마다 `Snapshot`을 찍어 이미지를 읽으면 수십 초가 지연되므로, **아래 10단계를 한 턴에 순서대로 바로 호출**한다:

1. `Click(loc=[1248, 400])` — RustDesk 연결 창 내 빈 공간을 먼저 클릭해 창 포커스 활성화 (비활성 Flutter 창에서 첫 클릭이 버튼 클릭 대신 창 포커스로만 소모되는 현상 방지)
2. `Move(loc=[1248, 458])` — 통화 `수락` 버튼 정중앙(`x: 1185..1315, y: 445..470`)으로 커서 이동 (`macos-mcp`의 `Click`은 `kCGEventMouseMoved`를 보내지 않으므로 Flutter 호버 인식을 위해 `Move` 필수)
3. `Wait(duration=1)` — 1초 대기
4. `Click(loc=[1248, 458])` — 통화 `수락` 버튼 클릭
5. `Wait(duration=2)` — 2초 대기 (통화 연결 후 같은 위치의 버튼이 `Audio input`으로 변경됨)
6. `Click(loc=[1248, 458])` — `Audio input`으로 변한 버튼 다시 클릭 (오디오 입력 팝오버 열기)
7. `Wait(duration=1)` — 1초 대기
8. `Move(loc=[1300, 448])` — 팝오버 상단 첫 번째 항목인 `시스템 소리` 행 정중앙(`y=448`)으로 커서 이동 (`y=468` 아래로 내려가면 두 번째 항목인 `MacBook Air 마이크`(`y=488`)가 선택되므로 반드시 `y=448` 사용)
9. `Wait(duration=1)` — 1초 대기
10. `Click(loc=[1300, 448])` — `시스템 소리` 라디오 옵션 클릭 (선택 완료와 함께 팝오버가 닫힘)

### 주의사항

- `App(mode="switch")`를 호출하지 않는다(호출 시 우측 상단 RustDesk 플로팅 연결 창이 최소화됨).
- `Snapshot`의 텍스트 접근성 목록(`Interactive Elements`)에는 RustDesk 내부 버튼이 나오지 않으므로 접근성 목록을 탐색하지 않는다.
- 기본 좌표로 동작하지 않은 경우에만 `Snapshot(use_vision=true)`으로 창 위치를 확인해 좌표를 보정한다.
- 통화 종료(`음성 통화 종료`), `연결 해제`는 절대 누르지 않는다.

## 완료 보고
